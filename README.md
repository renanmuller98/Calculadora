<h1>Calculadora Simples</h1>

## 📱 Sobre

 Bem-vindo à Calculadora Simples! Este projeto é uma calculadora básica desenvolvida com HTML, CSS e JavaScript. Ela permite realizar operações matemáticas fundamentais de maneira prática e intuitiva.

## 🎯 Funcionalidade

- Adição, subtração, multiplicação e divisão.
- Interface responsiva que se adapta a diferentes tamanhos de tela.
- Design moderno e minimalista.

## 🛠️ Ferramentas Utilizadas

- HTML5 - Estrutura da aplicação.
- CSS3 - Estilização e layout responsivo.
- JavaScript - Lógica de cálculo e interação com o usuário.

## 🌐 Demonstração

Você pode ver a calculadora em ação [aqui](https://calculadora-nine-orcin.vercel.app/).

## 🤝 Como Contribuir

Contribuições são bem-vindas! Se você tem ideias de melhorias ou encontrou algum problema, sinta-se à vontade para abrir uma issue ou enviar um pull request.

Clone este repositório: 

```bash
git clone https://github.com/seu-usuario/calculadora-simples.git
```
Navegue até o diretório do projeto:
```bash
cd calculadora-simples
```
Abra o arquivo index.html no seu navegador para começar a usar a calculadora.
